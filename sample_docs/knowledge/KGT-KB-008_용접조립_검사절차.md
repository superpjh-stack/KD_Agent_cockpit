# 용접조립 검사절차

문서번호: KGT-KB-008
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 품질
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 용접 조립 검사 절차 재작업 공정

## 목적과 범위
용접부번호, 적용 도면 Revision, 승인 용접절차서와 작업자 정보를 작업기록에 연결한다.

## 확인 절차
작업조건과 검사방법은 제품별 승인 절차를 따른다. 결함은 위치·검사결과·조치·재검사 기록으로 추적한다. 이 샘플은 전류·전압·예열온도 등의 운전조건을 지정하지 않는다.

## DB 연결 예시
OP-005 용접·조립은 계획 96시간, 누적 실제 61시간, 진행 상태다. 누적 공수만으로 잔여 35시간을 확정하지 말고 남은 작업 범위를 확인한다.
