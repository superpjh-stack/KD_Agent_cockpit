# 도면변경 관리절차

문서번호: KGT-KB-003
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 설계
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 도면 변경 리비전 재작업 승인 설계

## 목적과 범위
설계 변경 요청에는 도면번호, 이전·신규 Revision, 변경 사유, 영향 부품과 적용 작업지시를 기록한다.

## 확인 절차
설계 담당자는 재고품·재공품·발주품에 대한 변경 영향을 검토한다. 승인되지 않은 변경은 작업에 임의 적용하지 않는다. 재작업 여부는 영향 검토와 담당자 승인으로 결정한다.

## DB 연결 예시
VD-26002-GA Rev.B의 ECR-26002-03은 고객 승인대기다. 승인대기는 재작업 확정을 의미하지 않으며 영향 작업지시 정보가 추가로 필요하다.
