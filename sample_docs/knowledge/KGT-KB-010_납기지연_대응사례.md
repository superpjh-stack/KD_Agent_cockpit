# 납기지연 대응사례

문서번호: KGT-KB-010
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 생산관리
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 납기 지연 우선순위 승인 공정 발주

## 목적과 범위
지연 원인을 자재, 설계 승인, 생산 공정, 품질 재시험, 외주 일정으로 나누어 영향 작업을 연결한다.

## 확인 절차
생산 담당자는 필수 선행 작업과 확정 입고일을 확인해 회복계획을 작성한다. 구매·설계·품질 담당자가 필요한 승인과 담당자를 정리하고 고객 납기 변경은 책임자가 협의한다.

## DB 연결 예시
OP-006 특수표면처리는 발주 지연 상태이며 PO-26093은 7일 지연 예상이다. 프로젝트 최종 납기 미준수 여부는 후속 공정 일정까지 확인해야 판단할 수 있다.
