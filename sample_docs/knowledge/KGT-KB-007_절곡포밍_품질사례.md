# 절곡포밍 품질사례

문서번호: KGT-KB-007
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 제작
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 절곡 포밍 각도 변형 균열 공정 재작업

## 목적과 범위
절곡·포밍 전 적용 도면, 재질·두께, 금형 식별번호와 승인 작업조건을 확인한다.

## 확인 절차
각도 오차, 변형, 균열이 발생하면 위치와 측정값을 기록하고 품질·생산 담당자가 원인과 재작업 가능 여부를 검토한다. 목표 각도와 허용범위는 승인 도면을 따른다.

## DB 연결 예시
OP-002 포밍은 계획 20시간, 실제 22시간으로 2시간 초과했다. 공수 초과만으로 불량이나 재작업 발생을 단정하지 않는다.
