# 제조공정 전체흐름

문서번호: KGT-KB-001
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 생산관리
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 수주 견적 설계 공정 납기 승인

## 목적과 범위
수주·견적 → 설계 → 자재·구매 → 레이저 절단 → 절곡·포밍 → 용접·조립 → FAT → 출하·설치 순으로 작업 이력을 연결한다.

## 확인 절차
생산 담당자는 작업지시의 계획 종료일과 완료 상태를 확인한다. 자재 보류, 설계 승인 대기, 검사 불합격은 다음 공정 착수 전에 해당 담당자에게 확인한다.

## DB 연결 예시
KGT-26002는 용접·조립 진행 중이며 설계 변경 고객 승인대기와 씰 부족을 함께 확인한다. 실제 완료 가능일은 자재 확정 입고일과 잔여 작업계획이 있어야 판단한다.
