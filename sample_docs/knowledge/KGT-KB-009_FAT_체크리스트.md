# FAT 체크리스트

문서번호: KGT-KB-009
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 품질
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: FAT 품질 검사 불합격 진동 재시험 출하 승인

## 목적과 범위
FAT 기록에는 장비·시험항목·측정값·단위·판정기준 문서·결과·입회자·재시험 이력을 남긴다.

## 확인 절차
불합격 항목은 조치 후 승인된 절차로 재시험하고 품질 담당자가 결과를 확인한다. 출하에는 필수 시험 완료와 출하 승인 기록이 필요하다.

## DB 연결 예시
FAT-001 무부하 진동은 5.1mm/s, DB 데모 기준은 4.5mm/s 이하로 불합격이다. 재정렬 후 재시험 예정이다. 이 수치는 해당 가상 시험의 예시이며 다른 장비의 안전 기준이 아니다.
