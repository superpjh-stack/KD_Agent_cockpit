# 레이저절단 작업표준

문서번호: KGT-KB-006
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 제작
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 레이저 절단 커팅 작업 공수 공정 지연

## 목적과 범위
착수 전 작업지시, 적용 도면, 소재 LOT, 두께, 수량 및 승인된 장비별 작업조건을 확인한다.

## 확인 절차
절단 완료 시 실제 공수, 생산 수량, 불량과 잔재 이력을 기록한다. 출력·속도·가스 조건은 장비 매뉴얼과 승인 작업표준을 따른다. 이 샘플은 장비 운전조건을 제공하지 않는다.

## DB 연결 예시
OP-004 레이저커팅은 계획 15시간, 실제 14시간, 완료 상태다. 계획 대비 공수 차이와 납기 지연은 별개로 확인한다.
