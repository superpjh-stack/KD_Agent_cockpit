# 견적원가 산정지침

문서번호: KGT-KB-002
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 견적
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 원가 견적 비용 수익성 예산

## 목적과 범위
재료비, 외주비, 직접 작업 공수, 검사·물류비를 항목별로 산정하고 견적 개정번호를 기록한다.

## 확인 절차
예상 원가와 실제 누적 원가는 구분한다. 예산 대비 실적 분석에는 승인 예산과 실제 비용전표가 모두 필요하다. 예측치만으로 원가 초과를 확정하지 않는다.

## DB 연결 예시
KGT-26002 예상 원가 292백만원과 예상 이익률 8.8%는 미검증 데모 예측이다. 현재 DB에는 실제 비용전표가 없으므로 실제 초과 금액은 판단할 수 없다.
