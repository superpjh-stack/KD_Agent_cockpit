# 자재입고 검사기준

문서번호: KGT-KB-004
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 품질
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 입고 검사 보류 MTC 두께 치수 자재

## 목적과 범위
입고검사는 발주서, 자재 LOT, 재질, 수량, MTC 및 도면의 요구 치수와 측정값을 대조한다.

## 확인 절차
치수·두께 허용공차는 적용 도면이나 승인 검사기준에서 확인한다. 본 샘플은 생산용 공차를 지정하지 않는다. 보류 자재는 품질 담당자 판정 전 임의 사용하지 않는다.

## DB 연결 예시
ML-260902는 요구 두께 16.0mm, 측정 15.6mm이고 보류 상태다. 차이가 있다는 사실과 승인 공차 초과 판정은 구분한다. ML-260903은 MTC 문서 미비다.
