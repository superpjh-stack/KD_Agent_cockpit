# 자재부족 대체승인절차

문서번호: KGT-KB-005
개정번호: DEMO-1
적용 범위: 가상 제조 프로젝트
문서 담당: 구매
시행일: 미승인 샘플
상태: 검증용 예시 / 운영 사용 전 담당자 검토 필요
검색어: 자재 부족 입고 지연 납기 구매 대체 공급사

## 목적과 범위
부족 자재는 사용 가능 재고, 작업 필요량, 미입고 발주량, 확정 입고일을 대조한다.

## 확인 절차
구매 담당자는 공급사 납기를 재확인하고 대체 후보의 재질·치수·성능 및 문서를 설계·품질 담당자에게 검토 요청한다. 승인 전 대체 발주나 사용을 자동 실행하지 않는다.

## DB 연결 예시
ML-260904 PTFE 씰은 부족 상태다. PO-26088은 약속일 2026-09-06, 예상일 2026-09-11로 5일 지연 예상이다. 대성씰은 검토 후보이며 확정 공급사가 아니다.
