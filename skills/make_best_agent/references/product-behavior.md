# 제품 동작 기준

이 문서는 경동 에이전트의 최종 사용자 선택이다. 다른 회사나 새 요청에는 수정 가능하며 사용자 선택보다 우선하지 않는다.

## 화면

상단 회사 브랜드, 대화 제목 ‘경동 에이전트’. 왼쪽은 ‘추천질문리스트’와 질의이력, 오른쪽은 지식베이스와 데이터 대시보드다. 추천은 데이터·지식베이스·복합질문의 세 그룹, 각각 10개와 01–10 번호. 모바일에서도 질문 메뉴가 먼저다.

프로젝트 선택창은 생략한다. 초기 빈 대화 영역은 ‘오늘 궁금한거 질문해!!’만 표시한다. 입력창은 하단에 유지한다. 새 답변이 시작되면 첫 assistant 메시지의 상단을 대화 영역 위로 맞춘다. 전체 페이지를 스크롤하거나 답변의 끝으로 이동하지 않는다. 같은 턴에 음성 요약이 추가돼도 사용자가 읽는 위치를 유지한다.

비교는 원본 표를 먼저, 상세 분석과 다음 확인사항을 접힌 영역에 표시한다. 문서·DB 근거, 요청별 검사, 자료 출처는 펼칠 수 있다. 표는 자체 가로 스크롤을 사용하고 모바일 화면 전체를 넘치게 하지 않는다.

네이비·청록 포인트와 밝은 읽기 영역을 기본으로 한다. 작은 모바일 글 입력은 16px 정도로 유지하고 음성 버튼은 최소 44px 터치 높이를 확보한다. 안전 영역 여백, reduced-motion, 키보드 포커스를 보존한다.

## 대화와 음성

호출명은 요구하지 않는다. 추천 질문은 호출명 없이 바로 전송한다. AI 설정 여부를 화면에 정직하게 표시하되 ‘데모 조회’ 모드 선택을 사용자에게 강요하지 않는다. 샘플·미승인 상태는 출처 상세에 남긴다.

원래 질문의 모든 요청을 추적한다. 조회 결과가 존재하더라도 비교·원인·우선순위를 실제로 설명하지 못하면 추가 확인으로 남긴다. 빈 조회를 실제 사건 부재나 재고 0으로 해석하지 않는다.

새 발화는 이전 발화의 출력과 진행 중 조회를 중단하도록 요청한다. 세션 ID와 발화 ID를 구분해 연결은 유지하면서 오래된 이벤트를 무시한다. 도구가 끝난 후 도착하는 텍스트도 격리한다. ‘두세 문장 요약’은 긴 답변 앞부분 자르기로 대신하지 않는다.

후속 질문 대상은 사용자 발화와 유효한 프로젝트 정보를 기반으로 한다. 앞선 AI 답변에서 등장한 ID를 사실로 확정하지 않는다. ‘다른 프로젝트’에 대상이 없으면 물어보고, 새 대화 또는 범위 전환 후 이전 질문을 섞지 않는다.
