# 경동글로벌텍 AI Agent V4 · 지식그래프

기존 V3 대화·연구소·보고서에 Cytoscape.js 관계도 탭을 추가했다. 기존 실행 모듈 `v2.api`와 소스 디렉터리를 유지하며 화면과 health API는 V4/4.0.0을 표시한다. 별도 Neo4j 서버나 그래프 데이터 복제 없이 SQLite/PostgreSQL 원본을 읽어 노드와 관계를 생성한다.

## 사용

지식그래프 탭에서 프로젝트를 선택한다. 고객, 프로젝트, 설계·변경, 자재 LOT, 공정, FAT, 구매, 설비 측정, 클레임, 입고검사를 탐색한다. 노드 검색, 관계 종류 필터, 확대·축소, 전체 보기와 키보드로 선택 가능한 노드 목록을 제공한다. 노드 클릭은 원본 필드와 값을, 연결선 클릭은 연결 필드와 일치 값을 표시한다.

`GET /api/knowledge-graph?project_id=KGT-26001`은 기존 접근 코드 인증과 no-store 정책을 사용한다. 프로젝트 ID를 필수로 받고 알 수 없는 ID는 404를 반환한다. 각 기록은 project_id, 입고검사는 material_lot로 연결한다. 고객은 해당 프로젝트의 customer 필드에서 파생하며 고객 마스터 간 동일 기업 판정을 하지 않는다. 설계 리비전이 다르면 별도 노드다. 0과 미입력을 구분한다.

관계는 인과·작업 순서·승인을 의미하지 않는다. 문서의 의미 기반 연결, LLM 관계 추론, 그래프 기반 채팅 검색은 이번 범위에 포함하지 않는다. 조회 실패는 오류로 표시한다. 종류별 최대 200건이며 생략 시 경고한다. 원본 DB를 수정하지 않는다. 출처 상세에 기존 데이터의 가상·미승인 샘플 상태를 유지한다.

## 실행

프로젝트 루트에서:

```sh
npm ci --prefix v2/web
npm run build --prefix v2/web
./start-v4.sh
```

접속: http://127.0.0.1:8514. 로컬 기본값은 기존 SQLite DB이며 API 설정은 기존 환경을 사용한다. 포트 변경은 `KGT_PORT`로 지정한다. 설정된 PostgreSQL을 사용하려면 `KGT_USE_POSTGRES=1 ./start-v4.sh`를 사용한다. 현재 로컬 PostgreSQL(55432)은 연결 거부되어 실행 검증하지 못했다. V3 기능을 포함한 동일 코드의 새 버전이며 V3의 별도 서버 복제본은 만들지 않았다.

## 검증

- Python: `tests v2/tests` 68 passed, 1 skipped.
- TypeScript/Vite 프로덕션 빌드 통과.
- 1440px/390px: 프로젝트 전환, 노드 원본 표시, 입고검사 필터의 상위 경로, 검색, 확대, 탭 재진입, 늦은 조회 응답 격리, 가로 넘침 확인.
- API: 인증, 필수 인자, 미등록 프로젝트, 관계 끝점 정합성, 합격 검사 포함, 설계 리비전 분리, 0/null 보존, 표시 제한 검증.
- 운영 PostgreSQL, 외부 배포, 실제 AI·음성은 이번 변경에서 검증하지 않았다.

브라우저 검증: 서버 실행 후 `node v2/tests/browser-knowledge-graph.cjs`. Playwright가 별도 위치라면 `PLAYWRIGHT_MODULE`로 지정하고 접속 주소는 `KGT_URL`로 변경한다.

의존성 설치 시 기존 개발 도구 Vite/source-map-js의 npm audit high 2건이 확인되었다. 이번 변경에서는 관련 없는 도구 업그레이드를 하지 않았다. 그래프 라이브러리는 [Cytoscape.js 공식 문서](https://js.cytoscape.org/)의 내장 레이아웃과 이벤트 API를 사용한다.

## 지식그래프 추천질문

왼쪽에 전체 관계, 고객, 설계변경, 자재 LOT, 입고검사, 공정, FAT, 구매, 설비 측정, 클레임의 추천질문 10개를 제공한다. 클릭하면 지식그래프를 열고 해당 종류 필터를 적용한다. 이미 선택한 프로젝트는 유지하며, 없으면 사용자가 선택한다. 자연어 AI 답변을 생성하는 대신 관계도와 원본 기록으로 안내한다. 모바일 질문 패널에서도 동일하게 동작한다.

## 업무 중심 메뉴 개선

- 메뉴: AI에게 질문 / 문제 해결·개선 / 보고서 만들기 / 프로젝트 관계도.
- 왼쪽 질문은 프로젝트, 자재·구매, 생산·공정, 품질·문제, 문서·규칙의 다섯 그룹으로 분류한다. 기존 질문과 관계도 질문 10개를 유지한다. 검색 시 모든 그룹에서 일치하는 질문을 펼친다.
- 즐겨찾기와 최근 질문은 현재 브라우저 탭에 저장한다. 관계도 질문 이력은 선택 당시 프로젝트와 필터를 복원한다.
- 상단 작업 프로젝트를 대화·관계도·연구소·보고서에서 공유한다. 대상 변경은 진행 중 대화 요청과 음성을 취소하고 이전 대화를 비운다.
- 관계도는 고객·설비, 자재·공정·입고검사·FAT 기록 수, 입고검사 판정 건수와 주의 표시 기록 수를 원본으로 집계한다. 조회 제한이 있으면 일부 집계임을 표시한다.
- 주의 표시는 등록 상태(보류·불합격·부족·미첨부·높음·주의·발주 지연·조치중·고객 승인대기)와 해당 필드의 정확한 일치를 사용한다. 원인 추론이나 정상 판정을 생성하지 않는다.
- 상세 필드와 단위를 한국어로 표시한다. 자재에서 검사 기록, 질문 초안, 프로젝트 단위 보고서로 이동할 수 있다. 질문 버튼은 초안만 입력하며 전송은 사용자가 한다.
- 기록 없음, 검색/필터 결과 없음, 조회 실패를 구분한다. 프로젝트 범위 변경과 지연 응답 격리, PC/모바일, 추천 10개 유지, 즐겨찾기, 보고서/연구소 범위 공유를 브라우저에서 검증했다.
